No ratification record defines a rounding convention, so this report compares literally and does not pass them; whether those bounds or the comparison convention should be restated is a spec decision for the keys (see the caveats below).

Rule: ERROR if any input is in error; else FAIL if any ratified (binding) row fails its bound; else INCOMPLETE if any non-pending row lacks full valid grid coverage; else PASS. Superseded rows are context and never FAIL the report; measured rows carry no bound; Area is PENDING.

Comparison rule: Each ratified bound is compared literally: every valid grid point's raw measured value, scaled to the bound's unit, must satisfy the bound exactly as written in spec/target-spec.md (e.g. >= 37.8 means 37.7999 fails). No rounding, tolerance or precision convention is applied: no ratification record defines one, and choosing one is a spec decision, not the report's. The worst value rounded to the bound's written decimals is shown for information only and never gates a verdict. A point that fails its record's validity flags never contributes an extremum: it is counted as missing coverage, so a failed simulation point can only make a row INCOMPLETE, never PASS.

## Caveats that travel with these numbers

- Offset Monte Carlo (input-offset-mc) was run at a FIXED 1.20 V supply only: five <corner>_mismatch sections x {-40, 27, 125} degC. The supply axis (1.08 V / 1.32 V) is covered only by the deterministic systematic-offset record; no statistical figure here is a statement about 1.08 V or 1.32 V.
- Systematic and statistical offset are distinct evidence: the ratified bound is the systematic (nominal-device) half [DR-2]; the mismatch-driven 3σ half is measured [P] and is not ratified (DR-0002 residual (b), pending its own two-key pass). This report does not combine them into a ratified total.
- The CMRR row is ratified on its mismatch-inclusive figure [DR-4], whose definition (Av0 minus the +3σ point of the drawn-Acm distribution, mean + 3σ in the LINEAR domain, N = 300 + process corners) is part of the number. This report reads that per-point figure from the record and re-derives it from the record's own linear mean and σ (definition check cmrr_linear_3sigma); it never aggregates in the dB domain. The superseded systematic floor is shown as context only.
- Output swing is unloaded (CL = 2 pF, no resistive load): an upper bound. PSRR+ is ratified at the DC shelf and is strongly frequency-dependent.
- Every measured row comes from nominal-device deterministic benches except the two Monte Carlo records (offset, CMRR); no other row carries a statistical basis.
- Bound precision is an open spec question, not settled by this report: three DR-0002 bounds (integrated noise <= 108.9 µVrms, systematic offset <= 21.9 mV, swing span >= 0.571 V) are stricter than the raw worst case of the very records DR-0002 cites, which only round onto them (108.949 µVrms, 21.927 mV, 0.570958 V). This report compares literally, so those rows FAIL. Whether to restate the bounds or ratify a comparison convention is for the keys in a decision record: 2AMLogic/sg13g2-opamp#101.
- The four open-loop rows (DC gain, GBW, phase margin, Iq) read the corrected inn-AC-grounded record open-loop-ac (issue #241), which supersedes the inn-floating record open-loop-ac-floating-inn; the earlier DC-gain literal FAIL (37.7812 dB) was a reading of the superseded record and is preserved in the earlier reports, unedited. The corrected record's Iq column iq_a is the OP envelope's total VDD current, including the 10 µA ibias reference, and its Av0, GBW and PM are read from the AC envelope (PM = 180 + degrees(phase at the 0 dB crossing)).
- The corrected open-loop record is validated from its pinned klt-sim envelopes (definition check open_loop_klt_audit), not from the legacy op_pass / gm_status columns it does not carry. The legacy internal-node saturation proxy (vd1, vd2, vtail) and the gain-margin status are NOT re-measured by the corrected bench: the report relies on the DC operating point being unchanged by the AC ground element and joins the superseded record's op_pass as stated, disclosed evidence for that, confirmed by Vout and total VDD current agreeing with it to 10 µV and 10 nA. Fresh internal-node evidence would need a separately authorized run.
- The CMRR mismatch record joined its Av0 from the superseded inn-floating open-loop record, and its summary still states those Av0 values; this report keeps that join on open-loop-ac-floating-inn (selected, hash-pinned) rather than silently re-stamping the CMRR result as recomputed against the corrected Av0. The CMRR and PSRR figures are therefore not claimed to reflect the corrected open-loop record; that needs separately authorized new evidence.
- The corrected open-loop envelopes ran on the batch fleet, whose worker could not read the PDK release stamp (pdk_stamp_comparison not_comparable): the model deck is identified by its sha256 and the engine by its version, but run-time PDK release identity is not verified for this record (PDK provenance stays legacy/unverified).

A committed summary cell passes only when it is that recomputed value as the bench serializes it (printf %.9g, nine significant digits), i.e. within half a unit in the 9th significant digit (5e-9 relative); a cell that differs beyond its own serialization is an error naming the point and the offending field.
